# Code of conduct

ReviewDesk is used by students, researchers and librarians, many of them new to software projects. Everyone who
takes part here is asked to:

- be patient and polite, above all with someone asking a first question;
- criticise the work, never the person;
- keep to the subject: the software, its guides and how reviews are done with it;
- never post anyone's personal details, or a real review's records or decisions.

Insults, harassment and discriminatory remarks are not accepted. The maintainer may edit or remove such comments and
block people who repeat them.

To report a problem with someone's behaviour, use the same private route as for a security problem: **Report a
vulnerability** on this repository's **Security and quality** tab (GitHub used to call it **Security**), saying
that it is about behaviour. If that button is not there, open an issue that says only that you have something to
report privately, with no details, and the maintainer will arrange a private way for you to send it. Reports are
kept private.
